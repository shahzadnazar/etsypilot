89 · Accessibility annotations
Contrast and non-colour encoding
Verified Text 7.4:1 · each provenance badge carries an icon and a word, never colour alone
Estimated Text 5.9:1 · estimated values also use a dashed underline
▲ 12.4%▼ 3.1% Direction is shown by an arrow plus sign, so red/green is never the only cue
Chart series differ by pattern and line style as well as hue
Touch and hit targets
Mobile controls are a minimum of 44 × 44 px with 8 px separation. Desktop rows are 44 px tall with a full-row click target; checkboxes have a 40 px padded hit area.
Keyboard, focus and announcements
TabSkip link → sidebar → top bar → page actions → content, in visual order
⌘KCommand palette; Esc closes and returns focus to the trigger
SpaceToggles row selection; Shift+↑↓ extends a range
EscCloses drawers and dialogs; focus is trapped inside while open
Focused primary 2 px brand ring with 2 px offset on every interactive element
Screen reader behaviour
Provenance badges expose full text: “Estimated: modeled from public marketplace signals, medium confidence”. Ranges read as “1,200 to 1,850 US dollars, estimated”. Bulk progress and sync status use a polite live region; failures use assertive. Tables use real header semantics with a caption naming the period, currency and time zone.
