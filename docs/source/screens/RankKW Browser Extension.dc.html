Implementation notes
Chrome and Firefox share one UI, one API client and one auth flow (Manifest V3 for Chrome, WebExtensions-compatible for Firefox); only manifest and packaging differ. All data shown is mock, served behind the same abstraction the main app calls, so wiring the real Etsy API later only changes the backend adapter — no UI change.
